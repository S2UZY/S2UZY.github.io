# Today I Learned (2026-07-02)

## macOS 파일 접근 권한 (TCC)

- macOS에는 앱별로 파일·폴더 접근을 통제하는 TCC(Transparency, Consent, and Control)가 있다. 터미널에서 돌리는 도구가 갑자기 `EPERM`을 내며 파일을 못 읽는다면 이 권한부터 의심해 볼 만하다.
- `com.apple.macl`은 "이 파일·폴더는 특정 앱이 접근하도록 허용됐다"는 표시로 붙는 확장 속성이다.

## Claude Code `/security-review`

- `/security-review`는 현재 브랜치의 변경 사항을 보안 관점에서 검토해 주는 Claude Code 명령어다. PR을 올리기 전에 돌려 두면 인젝션이나 인증 누락 같은 문제를 일찍 잡을 수 있다.
