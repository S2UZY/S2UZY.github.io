# Today I Learned (2026-07-15)

## Nginx

- Nginx는 웹 요청을 받아 알맞은 곳으로 전달하는 가볍고 빠른 오픈소스 웹 서버다. 정적 파일 제공, 리버스 프록시, 로드 밸런싱, 캐싱에 두루 쓰인다.
- Apache보다 적은 리소스로 훨씬 많은 동시 접속을 처리할 수 있다는 게 강점이다.
- Nginx·Vite 개발 서버·Express 모두 결국 HTTP 요청을 받아 응답을 돌려주는 프로그램이라는 점에서는 같다.
