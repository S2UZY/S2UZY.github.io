# Today I Learned (2026-07-03)

## 커밋 SHA

- 커밋 SHA는 커밋마다 붙는 고유 ID다. 커밋 내용을 해시한 값이라, 같은 SHA면 정확히 같은 스냅샷을 가리킨다.

## 쿠버네티스와 EKS

- 쿠버네티스(Kubernetes)는 Docker 컨테이너를 자동으로 관리하는 운영 시스템이다. CPU 사용량이나 요청 수를 보고 서버 수를 늘리거나 줄이고, 배포할 때도 서비스를 끊지 않고 교체(무중단 배포)할 수 있다.
- EKS(Elastic Kubernetes Service)는 AWS가 쿠버네티스를 대신 운영해 주는 관리형 서비스다. EC2에 백엔드를 하나씩 직접 띄우던 방식과 달리, 백엔드·AI 서버·워커 같은 여러 서비스를 한 클러스터에서 함께 관리한다.

```text
AWS
 └ EKS
      ├ 백엔드 A
      ├ 백엔드 B
      ├ AI 서버
      └ Worker
```
