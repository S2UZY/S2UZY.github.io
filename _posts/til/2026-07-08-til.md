# Today I Learned (2026-07-08)

## Claude Code 플러그인 설치

- Claude Code는 플러그인 마켓플레이스를 추가한 다음 그 안의 플러그인을 설치하는 구조다. 마켓플레이스는 `/plugin marketplace add <저장소>`로 등록하고, 플러그인은 `/plugin install <이름>@<마켓플레이스>`로 설치한다.
- 플러그인에는 스킬·훅·명령어가 묶여 있어서, 한 번 설치하면 세션마다 같은 작업 규칙을 자동으로 적용할 수 있다.
