# Today I Learned (2026-09-10)

## Figma Code Connect

- Code Connect(피그마 커넥터)는 피그마의 디자인 컴포넌트와 실제 코드 컴포넌트를 연결하는 매핑이다.
- 매핑이 있으면 피그마 MCP 서버가 디자인을 코드로 옮길 때 이미 있는 컴포넌트를 정확히 가리킬 수 있어서, 구현 안내가 더 정확해진다.
