# Today I Learned (2026-07-09)

## ORM 선택: Prisma vs TypeORM

- Prisma는 DB 스키마 파일을 중심으로 움직인다. `schema.prisma`에서 타입 안전한 클라이언트를 생성해 주고, 마이그레이션 관리가 편하다.
- TypeORM은 엔티티 클래스를 먼저 만들고 그걸 테이블로 매핑하는 방식이다. TS 타입 지원과 마이그레이션 흐름을 보고 Prisma를 골랐다.

## Prisma 시작하기

- 설치는 CLI(`prisma`)는 개발 의존성으로, 런타임 클라이언트(`@prisma/client`)는 일반 의존성으로 나눠서 한다.

```bash
pnpm add -D prisma
pnpm add @prisma/client
pnpm prisma init
```
