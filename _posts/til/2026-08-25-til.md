# Today I Learned (2026-08-25)

## 로지스틱 회귀

- 로지스틱 회귀는 각 피처가 양성·음성 판단에 얼마나 영향을 주는지 가중치를 학습하는 분류 모델이다.
- `C`는 규제 세기를 조절하는 값으로, 작을수록 규제가 강해져 가중치를 더 억제한다. 데이터가 적을 때는 특정 피처에 과하게 맞춰지지 않도록 C를 기본값(1.0)보다 작게 둔다.
- `max_iter`는 가중치를 찾는 최대 반복 횟수이고, `random_state`는 같은 조건에서 결과를 재현하기 위한 시드값이다.

```text
C 큼   → 규제 약함 → 학습 데이터에 더 적극적으로 맞춤
C 작음 → 규제 강함 → 가중치를 더 억제
```
