# Today I Learned (2026-07-21)

## zod-to-openapi

- `@asteasolutions/zod-to-openapi`는 이미 만들어 둔 Zod 스키마를 OpenAPI(JSON) 스펙으로 변환해 준다. 검증용 스키마와 API 문서를 따로 관리하지 않아도 된다.
- OpenAPI는 API 문서의 표준 형식이고, Swagger가 읽는 JSON 스펙이 바로 이것이다.

## swagger-ui-react

- `swagger-ui-react`는 OpenAPI JSON을 받아 Swagger 화면으로 렌더링하는 React 컴포넌트다.

```text
Zod Schema → zod-to-openapi → openapi.json → swagger-ui-react → /docs
```
