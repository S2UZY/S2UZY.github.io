# Today I Learned (2026-07-14)

## 로드 밸런서

- 로드 밸런서는 들어온 요청을 여러 서버(파드)로 나눠 보내 부하를 분산한다.
- AWS ALB(Application Load Balancer)는 HTTP 전용 로드 밸런서로, 요청을 쿠버네티스 Service로 넘기고 Service가 다시 살아 있는 파드들에 전달한다.

```text
Internet → AWS ALB → Kubernetes Service → Pod1 / Pod2 / Pod3
```
